# 0.17.8 三星内购实机验收记录

代码版本：0.17.8 / 26。包名：`com.ycolor.team.phytoy.camera.android.galaxyapp`。

状态：客户端五商品逻辑已完成开发；自动化结果见 `reports/iap_lifetime_0_17_8_20261011`。用户已确认商品和测试账号配置完成，并明确由自己后续执行实机付款、重装恢复和退款测试；当前任务只完成客户端逻辑和自动化检查。未观察到真实订单前，不把以下项目标记为通过。

签名必须与 Seller Portal 测试包一致。正式候选包由 `tools/package_android_release.py --channel galaxy` 生成，位于 `android/sample/build/outputs/apk/galaxy/release/sample-galaxy-release.apk`。不要上传 benchmark/debug 包。

| 项目 | 操作与期望 | 实机结果 |
| --- | --- | --- |
| 五商品查询 | 四单品 $5.99、全相机包 $19.99 的美元地区后台基准价；其他地区以商店实际返回价格为准。核对五个精确 ID 和 Item 类型。 | 待验收 |
| 单品购买 | 分别购买四单品；确认发货并保存后仅对应款可拍摄保存。 | 待验收 |
| 全相机包 | 选择 camera_all_lifetime，确认商店价格；校验、确认发货后六款现有相机均可拍摄。设置页显示全相机永久权益。 | 待验收 |
| 取消 | 从商店确认页取消，不新增权益，不影响已有单品。 | 待验收 |
| 离线与重启 | 完成购买后关闭网络并重新启动，已验证相机可继续使用；收据服务暂时失败不撤销缓存。 | 待验收 |
| 支付中断 | 支付后切后台／断网，恢复网络并恢复购买；不提前解锁、不重复付款。 | 待验收 |
| 重装恢复 | 先记录本应用偏好，确保可重建；保持已保存照片；卸载重装测试包后使用同三星账号恢复，重新校验并确认全包／单品权益。 | 待验收 |
| 全包退款 | 保留一个独立单品订单，撤销全包并成功联网恢复；仅撤销全包，独立单品仍可拍摄。 | 待验收 |
| 单品退款 | 全包有效时撤销单品，所有相机仍可用；没有全包时仅该单品锁定。已保存照片保持可回看。 | 待验收 |
| 账号与空订单 | 用户自行切换测试账号，成功权威查询只保留该账号有效订单；不读取或记录账号密码／付款方式。 | 待验收 |
| 可访问性 | 默认与 200% 字号检查选项、当地价格、升级不抵扣说明、恢复、返回，TalkBack 说明选中状态。 | 待验收 |

未来新增相机的权限已通过纯权益策略测试：全包授予未配置单品 SKU 的未来相机；四个单品不会授予未来权益。当前发行版本不添加假相机来替代真实功能。

调试日志标签 `ToviBilling` 只记录公开商品 ID、价格、币种、连接状态和权益结果，不打印原始收据、支付凭据或账号资料。验收记录只保留脱敏的订单证据，不把购买 token、密码或完整支付信息写入版本库。

三星生产模式的免费许可证测试需同时满足 Closed Beta 和许可证测试账号；仅加入许可证测试名单但不在 Closed Beta 仍可能收费。打开付款单后先核对实际金额和测试提示，不能把付费购买当成免费测试。[三星官方操作模式说明](https://developer.samsung.com/iap/test-guide/iap-operation-modes.html)

退款／撤销操作需要登录具备相应权限的商店账号。退款不应通过修改本地权益或注入假订单模拟为“实机验收通过”。收据模拟和 UI fixture 仅作为自动化测试证据。
