# Style illustrations

The cafe scene was generated with the built-in ImageGen tool on 2026-10-06.
It is an illustrative AI scene, not a photograph captured by ToviCam. There are
no external photographs, faces, logos or camera-maker sample assets.

The six WebP illustrations are generated by the project's Python reference
pipeline with the shipped style profiles and the same seed. Original/processed
pairs use matching crops. The purchase page labels them as illustrations and
explains that actual photos depend on the device and light. They do not certify
preview/still fidelity or physical camera accuracy.

Regenerate with `python3 tools/render_style_samples.py`; the source, profile and
output fingerprints are recorded in `manifest.json`.
