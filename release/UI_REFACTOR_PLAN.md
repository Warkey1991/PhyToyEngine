## 真实数据与可用交互

- 倍率档位由设备范围过滤，不伪造不支持的 0.5×。EV 和变焦继续调用原参数回调，捕获中的参数冻结/禁用规则保留。
- 解锁价格、可购买/忙碌/待确认/已拥有/不可用状态来自原商店控制器。未配置支付时主按钮保持禁用；试用、恢复、重试仍可在正文滚动区域到达。
- Select 只选本应用当前库中的真实照片。单张分享复用原 PhotoStore Intent；多张使用这些已验证 URI 的系统分享及读取授权，无批量删除或后台上传。
- Favorite 存于独立 `tovicam_photo_ui` UI 偏好，按 URI 区分，不改照片字节、编码、EXIF、MediaStore 索引或设置存储。
- EXIF 信息通过后台只读流获取，有请求代次/当前照片/页面可见性保护。显示真实画幅、像素、时间、ISO、光圈等；缺失字段省略，不复制稿件的固定 12MP/f1.8/ISO50。
- 设计稿的 GPS 保存开关需要新的定位/照片元数据能力，本轮保持此前“不改底层拍照逻辑”的范围。设置页只呈现项目已有真实选项，保留全部原设置、恢复购买和确认重置规则。

## 布局及无障碍

黑金主题统一为近黑背景、暗渐变卡片、金色强调和圆角主按钮。正文使用 sp；显示尺寸不足或字体放大时重排/滚动，保持至少48dp实际触摸目标。拍摄页保留设备刘海和导航安全区，隐藏状态栏以贴合稿件。真实回看照片完整适配，放大后才允许拖动；不会为模拟稿件画幅裁掉照片边缘。

页面继续移除被遮挡背景的无障碍节点，保留返回、参数调整、缩放、复位和照片切换的显式操作。系统分享只打开选择器，真正发送由用户决定；删除沿用确认和系统授权。

## 不变边界

保持 Camera2/3A、拍摄参数快照、闪光灯策略、画幅/旋转/镜像、编码及 EXIF 写入、照片保存/索引、SettingsStore、购买授权、SDK 和 native 引擎/profile/shader。MainActivity 本轮只改变状态栏/预览 UI 边距，以及风格详情卡片的已有授权查询与页面导航绑定。

引擎和受保护文件 diff 核对、两渠道构建、单元测试以及 UI 截图/回归的准确范围见本轮验收记录。模拟器截图只验证界面；真实成像、实际商店结算及完整多指/TalkBack仍需对应设备验收。
