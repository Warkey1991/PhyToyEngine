The .ptp files in this directory are compiled, integrity-checked runtime packages generated
from the corresponding JSON files under profiles/authoring. Regenerate them with
reference/phytoy_ref/profile_package.py whenever a versioned source profile is added.
The Android sample currently packages Digital 01, Plastic 82, Street 84, Fisheye 05 and
DH 2++ daylight studies v0.1.0, v0.2.0 and v0.3.0 (public-sample approximation, not hardware calibrated).
DH 2++ monochrome study v0.1.0 adds linear-luminance mixing and its own contrast curve.
Daylight v0.4.0 and monochrome v0.2.0 retain more texture; mono v0.2.0 opens shadow grays.
